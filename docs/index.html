Ce este Tarotul?

Tarotul este o hartă arhetipală a experienței umane, un instrument de introspecție ce îmbină simbolismul cu intuiția.

Fiecare dintre cele 78 de cărți oglindește o etapă a vieții sau o energie specifică. Descoperă cum poți folosi aceste simboluri pentru a câștiga claritate în prezent.
